# DonateConnect

DonateConnect is a frontend-based donation platform designed to connect donors with NGOs. It focuses on connecting donors with NGOs and presenting donation information clearly.

## About the Project

The project provides a user-friendly interface where users can explore NGOs, make donations, track donation information, view transparency records, and check donation delivery proof.

## Main Features

* Attractive and responsive homepage
* Donation form for different donation types
* NGO listing page
* Donation tracking page
* Transparency information
* Donation delivery proof section
* NGO dashboard interface
* About Us page
* Contact Us page
* Navigation between all major pages

## Project Structure

```text
DonateConnect/
│
├── index.html
├── donate.html
├── ngos.html
├── track.html
├── transparency.html
├── donation-proof.html
├── ngo-dashboard.html
├── about.html
├── contact.html
└── README.md
```

The HTML files represent different sections of the DonateConnect website. `index.html` is the homepage, while the other files provide donation, NGO, tracking, transparency, proof, dashboard, About Us, and Contact Us functionality through separate frontend pages.

## Technology Used

The current project is developed as a frontend website using HTML, CSS, and Bootstrap 5.3.3. The pages use responsive layouts, navigation bars, forms, cards, sections, and visual elements.

## Current Status

The current version is a frontend prototype. Backend, database, and payment gateway functionality are not implemented yet. Some information is presented as sample or demonstration content.
